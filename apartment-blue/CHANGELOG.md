# Changelog

## Unreleased

- Brighten the title button rims. Hover for a red close button, amber maximize and restore buttons, or a sage green minimize button.
- Add small icons for Caja’s Places sidebar.

## 0.5.0

- Add Marco and Xfwm window borders with the same graphite buttons as the GTK title bars.
- Style Caja, Thunar, the MATE and Xfce panels, and Xfce notifications.

## 0.4.5

- Match GTK 3 and GTK 4 window backgrounds and active controls to the libadwaita palette.
- Use the same muted blue for checks, switches, slider fills, progress bars and text selection.

## 0.4.4

- Restore the width and padding of Cinnamon notification banners so they appear on screen.

## 0.4.3

- Redraw the graphite title buttons as SVGs with a softer lower rim.
- Use the same artwork for all four window decoration paths, including the restore button.

## 0.4.2

- Give the title buttons a shaded graphite face and reveal their symbols on hover or focus.

## 0.4.1

- Match the standard title bar height and window controls across Cinnamon, GTK and libadwaita.
- Draw each resting glyph inside the same recessed circle.

## 0.4.0

- Added update and uninstall commands for unmodified installations, including earlier previews.
- Generated the libadwaita stylesheets from the shared palette and chrome.
- Added quiet silver glyphs to the recessed window controls.
- Added a full terminal palette and importable profiles.
- Documented the licences and the origin of the Nightjar artwork.

## 0.3.0

- Replaced the large window buttons with 12 px silver-edged controls.
- Aligned the GTK, Cinnamon and libadwaita menus and title bars.
